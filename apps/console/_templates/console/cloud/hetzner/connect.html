Setup Guide

Follow these steps to create your Hetzner Cloud API token:

1

Go to Cloud Console

Navigate to the Hetzner Cloud Console and select your project

2

Access Security Settings

Click on "Security" in the left sidebar, then go to the "API Tokens" tab

3

Generate API token

Click "Generate API Token" and set the following:

Token Configuration:
  • Name: "CloudMoo" (or your preferred name)
  • Permissions: Select "Read" (readonly)
4

Save your token

Copy and securely store your API token immediately

Important: The API token will only be displayed once. Make sure to copy it immediately after generation.
