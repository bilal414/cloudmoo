Setup Guide

Follow these steps to create an IAM user with the necessary permissions:

1

Go to AWS IAM Console

Navigate to the AWS IAM Console

2

Create a new IAM user

Create a new IAM user with programmatic access (Access Key and Secret Key)

3

Create a custom policy

Create a new policy with the following permissions:

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "ec2:DescribeInstances",
                "ec2:DescribeInstanceStatus",
                "ec2:DescribeVolumes",
                "ec2:DescribeVolumeStatus",
                "ec2:DescribeTags",
                "ec2:DescribeRegions",
                "ec2:DescribeAvailabilityZones"
            ],
            "Resource": "*"
        }
    ]
}
4

Attach the policy to the user

Attach the newly created policy to your IAM user

5

Save credentials

Save the Access Key ID and Secret Access Key provided - you won't be able to see the secret key again
